# VisaManager Pro

Logiciel de gestion de cartes Visa prépayées.

## Fonctionnalités

- **Tableau de bord** : Vue d'ensemble du stock, des ventes et des dettes.
- **Stock** : Gestion des cartes (ajout par lot, recherche, filtres).
- **Partenaires** : Gestion des revendeurs, distribution de cartes, encaissement.
- **Agence** : Gestion du stock et des ventes de l'agence.
- **Rapports** : Graphiques mensuels et historique des transactions.

## Configuration Firebase

1. Acceptez les conditions d'utilisation de Firebase si ce n'est pas déjà fait.
2. Le fichier `firebase-applet-config.json` sera généré automatiquement.
3. Les règles de sécurité Firestore (`firestore.rules`) sont déjà configurées.

## Utilisation

1. Connectez-vous avec votre compte Google.
2. Ajoutez des cartes via le bouton "Nouveau Retrait Banque" dans l'onglet Stock.
3. Créez des partenaires dans l'onglet Partenaires.
4. Distribuez des cartes aux partenaires ou transférez-les à l'agence.
5. Enregistrez les paiements et suivez les rapports.
